# Khuda Bux — Developer Portfolio

A lightweight, responsive personal portfolio built with HTML5, CSS3 and vanilla JavaScript.

## Overview
The site presents Khuda Bux as a Computer Systems Engineering student and developing professional focused on web development, AI/ML, AI agents, AI automation, API integration and software development.

## Features
- Responsive mobile-first design
- Dark/light mode with localStorage
- Sticky navigation and mobile menu
- Active section navigation
- Smooth scrolling
- Scroll-reveal animations
- Back-to-top button
- Accessible labels, focus states and reduced-motion support
- SEO metadata
- Open Graph and Twitter/X metadata
- Person and WebSite structured data
- robots.txt and sitemap.xml
- GitHub Pages compatible
- No frontend API keys
- Clearly marked editable placeholders

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- Schema.org JSON-LD

## Installation / Local Preview
1. Download or clone the repository.
2. Open the folder in VS Code.
3. Put your real profile image in `images/profile/`.
4. Put project images in `images/projects/`.
5. Put your CV at `assets/resume/Khuda-Bux-CV.pdf`.
6. Open `index.html` with VS Code Live Server, or double-click it for a basic static preview.

## Customization

- `YOUR-LINKEDIN-USERNAME`
- `YOUR-EMAIL@example.com`
- `YOUR-FIVERR-USERNAME`
- `EDITABLE`
- `PLACEHOLDER`

Replace these with verified information before publishing.

## Contact Form
The static site uses a FormSubmit-style action as a simple placeholder. Replace the email address in `index.html` before use. For a production backend, connect a secure serverless/API form provider. Never place secret API keys in frontend JavaScript.

## Deployment — GitHub Pages
1. Create a GitHub repository.
2. Upload all files while preserving the folder structure.
3. In GitHub, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select your main branch and `/root` folder.
6. Save and wait for the Pages URL.
7. Update the canonical URL, Open Graph URL, structured data URL and sitemap URL with your real Pages URL.
8. Commit the changes.
